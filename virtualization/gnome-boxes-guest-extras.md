# gnome-boxes-guest-extras

Extras include features such as clipboard sharing, dynamic monitor size scalling e.t.c

For folder sharing, refer to `gnome-boxes-share-folder.md`.

## Windows

On the guest, install `spice-vdagent`. ([Spice-space.org Downloads](https://www.spice-space.org/download.html))

## Linux

On the guest, install `spice-vdagent`.

> For many distros, you can just search for it on the software manager and install it from there.

> On APT based distros (Ubuntu, Linux Mint e.t.c): `apt install spice-vdagent`.
